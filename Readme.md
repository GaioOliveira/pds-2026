# Repositório da Disciplina PDS do curso TSI - 2026

## Aulas 

### Semana 1
* Apresentação da disciplina: metodologia de trabalho e avaliações;
* Avaliações individuais: Semana 9 e Semana 14;
* Entendo o porquê de projetar um software;
* Definição de problema para o projeto de aplicativo;
* Organização dos trabalhos em repositório do GitHub.

### Semana 2
* Entender o papel do Diagrama de Casos de Uso;
* Criar um Diagrama de Casos de Uso a partir de um problema.
* Elaborar a Descrição Textual de em Caso de Uso.
* Acesse o material da [Semana 2](./semana2)

### Semana 3
* Compreender o papel e as partes componentes do Diagrama de Sequência;
* Criar um Diagrama de Sequência para um Caso de Uso de um dado problema.
* Acesse o material da [Semana 3](./semana3)

### Semana 4
* Compreender o papel dos fragmentos combinados e estereótipos em Diagrama de Sequência;
* Criar um Diagrama de Sequência para um Caso de Uso de um dado problema.
